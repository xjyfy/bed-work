# 躺平工作

把一台 Android 手机当成 Windows 电脑的**遥控器 + 麦克风 + 文件通道**：同一局域网内 WebSocket 直连，不经过任何云端。

扫码绑定 → 手机按键遥控电脑的键盘鼠标与媒体播放 → 对着手机说话直接在你常用的输入法里上屏 → 手机与电脑互传文件。

用它一边刷剧，一边使用语音转文字遥控你的AI工作，不用端坐在桌子前。集成了文件传输功能，不用经过第三方服务器，在家用场景可以直接替代localsend使用

## 功能一览

| 能力 | 怎么用 | 说明 |
| --- | --- | --- |
| 键鼠遥控 | 方向九宫格 / 滚轮 / 媒体键 | 直接映射标准键盘，视频网站的方向键切集、空格播放全都可用 |
| 语音输入 | 「按住说话」（双击常开） | 16 kHz PCM 写入 VB-CABLE 虚拟声卡，微信输入法等从 `CABLE Output` 拾音上屏；声卡没就绪就整体禁用，**绝不回落扬声器** |
| 快捷应用 | 底部四个桌面式图标 | 已在运行（含最小化/在屏幕外）只切窗口不新开实例；没运行才启动 |
| 远程粘贴 | 「远程粘贴」 | 电脑端写剪贴板，必要时自动补 `Ctrl+V`（Electron/Qt 应用只认粘贴） |
| 截屏 | 「截屏」 | 全屏截图缩到长边 1600 的 JPEG，**全程不落盘**，手机可双指缩放 |
| 双向传文件 | 「传照片/视频」「传文件」 | 手机端零存储权限（Photo Picker / SAF）；单文件 ≤2 GB、一次 ≤50 个；电脑端可改接收目录、可按遥控器开关接收 |
| 多遥控器 | 扫码绑定 | 先连优先，托盘或设置页手动指定控制权 |

## 快速开始

**普通使用**：从 [Releases](https://github.com/xjyfy/bed-work/releases/latest) 下载 `RemoteMicSetup-1.0.0.exe` 安装 → 电脑托盘「设置…」生成二维码 → 手机 App 扫码绑定 → 开始使用。

**语音要额外一步**：把输入法的麦克风设为 `CABLE Output (VB-Audio Virtual Cable)`（安装包会自动装好这个虚拟声卡）。

**开发调试**：

```powershell
cd pc-service
.\安装依赖.bat
.\启动电脑端服务.bat
```

## 安全提示

- 服务监听 `0.0.0.0:8765`，请只在可信局域网使用；绑定 token 泄露后在设置页删除该遥控器并重新扫码。
- 防火墙只放行「专用/域网络」的 8765；手机连不上先确认当前网络不是「公用网络」。
- 安装包与驱动均未做商业代码签名，首次运行 SmartScreen 会提示未知发布者。
