# RemoteMic v1.2.7 / 电脑端 1.1.5

本次给「四个快捷应用栏位」补上新会话快捷键，并把所有快捷键输入改成**按键捕获**。

## 新会话快捷键（按栏位分别设置）

手机端「新会话」按钮以前是写死的 `Ctrl+N`。现在每个栏位可以单独指定：

| 优先级 | 来源 |
| --- | --- |
| 1 | 该栏位自己的新会话键（`slot_new_chat_hotkey`） |
| 2 | 按前台程序 exe 匹配（`new_chat_hotkey[exe]`，非栏位应用，如浏览器） |
| 3 | 全局默认（缺省 `Ctrl+N`） |

- 前台窗口属于哪个栏位就自动用哪个栏位的键——和发送键同一套「按窗口匹配」逻辑（普通 exe 按文件名，UWP/商店版按 PackageFamilyName）。
- 栏位里设成「无（禁用）」= **这个应用里不发任何键**：手机端会明确弹出「该应用禁用新会话」，不会按了没反应。
- 手机端不用升级协议：`new_chat` 语义码不变，内容由电脑端按当前窗口决定。

## 快捷键输入改为"点一下再按键"

设置页四个栏位的「发送」「新会话」两组快捷键都不再是下拉框，改成点击后直接捕获：

- 点按钮 → 显示「请按组合键…」→ 按下组合即生效（显示为 `Ctrl+Shift+F7` 这样的规范写法）
- **退格 = 无**；**Esc = 取消**、不改动
- 支持 `Ctrl/Alt/Shift` + 字母、数字、`F1~F12`、方向键、`Insert/Delete/Home/End/PgUp/PgDn`、`Enter/Tab/Esc/Space`、`- = [ ] ; ' , . /` 等单字符
- `Ctrl+W`、`Ctrl+R`、`F12`、`Ctrl+Shift+I/J/C` 这类会被 WebView2 吃掉或直接关窗的组合，捕获时直接拒绝并提示
- 新会话那一行右侧有 `↺`，一键恢复默认 `Ctrl+N`
- 语义差别（保留）：**发送键「无」= 不覆盖、按前台程序回落**；**新会话键「无」= 该栏位禁用**

## 升级说明

- 老配置零迁移：没有 `slot_new_chat_hotkey` / `new_chat_hotkey` 字段时行为与之前完全一致（`Ctrl+N`）。
- 历史 `slot_send_hotkey` 的列表格式继续可读，只在改动过的项写新格式。
- 安卓 1.2.6 → 1.2.7、电脑端 1.1.4 → 1.1.5 均可覆盖安装，绑定保留（同签名 `6567fa4f…`）。
- 电脑端升级后需重启服务（静默安装不会自动起服务）。

## 已知限制

- `Win` 键组合在 WebView2 页面里捕获不到，所以语音键（`Ctrl+Win`）仍是内置固定值，不在本次可编辑范围。
- 手机端目前没有"申请控制权"入口（沿用 v1.2.6 状态）。
