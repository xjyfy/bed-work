## 发布说明（`docs/release-notes-*.md`）

| 版本 | 要点 |
| --- | --- |
| [v1.2.2](release-notes-v1.2.2.md) | **下拉快捷开关（控制中心磁贴）**：点「遥控麦」磁贴直接切到应用；不承载状态、不常驻，Android 14+ 走 `PendingIntent` 适配；电脑端沿用 1.1.1 |
| [电脑端 v1.1.1](release-notes-v1.1.1.md) | 修「抖音最大化 + 悬停任务栏」截屏无响应 / 偶现未连接：托盘 GDI 移出事件循环、截屏回包发当前连接 |
| [v1.2.1](release-notes-v1.2.1.md) | **独立 release 签名**（升级需卸载重装、keystore 存 signing/ 不进 Git）+ **全新应用图标**；电脑端沿用 1.1.0 |
| [v1.2.0](release-notes-v1.2.0.md) | **稳定性与安全加固**（手机端 1.2.0 + 电脑端 1.1.0）：transfer_id 路径穿越、重连抢控制权、音频锁阻塞、文件传输握手与背压、声卡未就绪禁用语音键、日志脱敏、allowBackup 关闭 |
| [v1.1.0](release-notes-v1.1.0.md) | **手机端全新界面**：环形方向键、浅蓝语音键 + 波形动画、玻璃质感抽屉/设备下拉、边到边状态栏、退格长按加速连删；电脑端沿用 1.0.3 |
| [v1.0.3](release-notes-v1.0.3.md) | 覆盖安装自动关闭托盘进程（不再弹「选择操作」） |
| [v1.0.2](release-notes-v1.0.2.md) | 托盘「发送文件到手机」点了没反应修复；取消自签签名；audio 可观测、托盘传输进度、重连可观测 |
| [v1.0.1](release-notes-v1.0.1.md) | 安装包误报 WebView2 / VB-CABLE 修复、status 可见性、图标缓存、UWP 前台（含已废弃的自签签名） |
| [v1.0.0](release-notes-v1.0.0.md) | 首个可安装版本 |
