# v1.0.0 · 双向文件互传 + 托盘发送 + Windows 安装包

首个可安装版本：手机当遥控器、麦克风和文件通道，全部走同一局域网，不经过云端。

## 新增

- **手机 ↔ 电脑双向文件互传**
  - 手机端零存储权限：选图/视频走系统 Photo Picker，选任意文件走 SAF
  - 单文件 ≤ 2 GB，一次 ≤ 50 个，不做断点续传，失败/取消的 `.part` 自动删
  - 电脑端默认落系统「下载」目录，可在设置页改；每台遥控器单独开关「接收文件」，默认开
  - 进度浮窗（含「后台传递」按钮）+ 传输期短时前台服务在通知栏显示进度
- **托盘右键**新增「发送文件到手机…」与「开机自动启动」（勾选项，写 HKCU Run）
- **设置页**「音频输出」卡片：未检测到 VB-CABLE 时显示「安装虚拟声卡」按钮，装完自动重开输出流；等价命令行 `RemoteMicService.exe --install-driver`
- **Windows 安装包**（Inno Setup 6）
  - 装到 `%ProgramFiles%\RemoteMic`，运行期数据在 `%LOCALAPPDATA%\RemoteMic`
  - 内置 VB-CABLE 驱动（静默安装，已装则跳过）与 WebView2 引导器（缺失时才联网装）
  - 自动添加防火墙规则（仅专用/域网络）、可选开机自启、可选桌面图标
  - 卸载时询问是否一并卸载驱动、是否删除含 token 的配置

## 修复

- 关闭握手堵死事件循环导致手机每 10 秒掉线（`pong` 超时）
- 快捷应用对「窗口在屏幕外（-21333）」的目标返回成功但用户看不见
- 手机端两处必崩点：后台线程调 `Toast`、前台服务超时未 `startForeground`
- 通知栏进度被折叠进静默通知（channel 升到 DEFAULT）

## 已知限制

- 仅同一局域网；音频为未压缩 PCM（16 kHz/16 bit/单声道）
- 不做后台常驻保活：熄屏断连属预期，亮屏自动重连（实测 0.3 s）
- 安装包与驱动均未做商业签名，SmartScreen 首次运行会提示「未知发布者」
- 安装包尚未在「干净机器」上做完整装→用→卸回归

## 安装

下载 `RemoteMicSetup-1.0.0.exe` 双击安装（管理员一次 UAC），手机端扫码绑定后即可使用。
覆盖安装不会丢 `config.json` 里的绑定 token 与四栏位配置。

详见 [安装与使用](../docs/安装与使用.md)。
