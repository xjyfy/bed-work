# 功能说明

> 面向使用者与接手开发者：这个工具**能做什么、边界在哪、为什么这么设计**。
> 首次安装请先看 [安装与使用](安装与使用.md)；协议细节见 [架构与协议](架构与协议.md)。

手机遥控麦把一台 Android 手机变成 Windows 电脑的「遥控器 + 麦克风 + 传输通道」。手机与电脑在同一局域网，通过 WebSocket（`0.0.0.0:8765`）直连，不经过任何云端。

---

## 一、一句话总览

| 能力 | 手机端入口 | 电脑端落地 |
| --- | --- | --- |
| 键鼠控制 | 环形方向键、滚轮、媒体键 | 注入标准键盘事件（含组合键） |
| 语音输入 | 「按住说话 / 双击常开」 | 16 kHz PCM 写入 VB-CABLE `CABLE Input`，输入法从 `CABLE Output` 拾音 |
| 快捷应用 | 底部四个桌面式图标 | 已在运行→切窗口（含从屏幕外搬回）；没运行→启动 |
| 远程粘贴 | 「粘贴」 | 写剪贴板，必要时补 `Ctrl+V` |
| 截屏看电脑 | 「截屏」 | 抓全屏→缩到长边 1600→JPEG，只在内存里传 |
| 双向传文件 | 「照片」「文件」 | 落系统「下载」目录（可改），托盘也能往手机发 |
| 多遥控器 | 扫码绑定 | 先连优先，托盘/设置页手动指定控制权 |

## 二、手机端功能

### 2.1 按键控制

> **2026-11-21 界面改版（Android 1.1.0）**：媒体区、工具与文件区改为图标 + 短标签；工具与文件互传合并为一张卡；方向键改为小米遥控器式**环形**（`RingPadView`）；语音键改用浅蓝色系、说话中加深一档并显示循环波形；退格支持长按加速连删；顶部设备名可点开已绑定设备的下拉列表，设置入口改为底部玻璃抽屉；顶栏/媒体区压缩，给方向区让出空间；已按状态栏/导航栏 inset 留白。下列按键表按动作列出，控件外观以 App 为准。

方向键与确认/取消映射为标准键盘事件：`↑↓←→`、`Enter`、`Esc`、`Backspace`，媒体键 `播放暂停 / 上一首 / 下一首`、`音量 ±`、滚轮上/下、`Alt+Tab`（切换应用，浮层内用方向键移动）、`Ctrl+1..9`（切换 Tab 循环）、`Ctrl+N`（新会话）。纸面分区见下方「手机端按键全表」。

- **不搞自研手势**：实测绝大多数视频网站/播放器认方向键（↑↓ 切视频、←→ 拖进度、空格 播放暂停），直接映射标准键盘行为最稳、覆盖面最广，因此没有触摸板、没有滑动音量条、没有三段式手势。
- **「视频播放/暂停」** 是独立的空格键，和媒体键的「播放暂停」分开，因为浏览器里的视频只认空格。
- 长按/连击频率由手机端限流，避免刷爆电脑端的键鼠注入。

#### 手机端按键全表（按界面分区）

手机端界面自上而下分 6 个区（顶栏、媒体、工具与文件、方向、语音、快捷），下表按实际排列顺序写。「电脑端动作」列是真正注入的键；标「可配」的来自 `config.json`，改完手机端无需重装。

**1. 顶栏**

| 设备名（未绑定时显示「未绑定设备 · 点击扫码」） | 无（本地交互） | 未绑定：点一次直接进扫码页。已绑定：弹下拉列表（● 在线 / ○ 未连接，当前设备带对勾），点一行即切换；列表底部「绑定新设备」进扫码 |
| 设置 | 无（本地交互） | 打开绑定对话框：扫码绑定设备（唯一入口，不再提供手动输入） |

| --- | --- | --- |
| 应用1~4 | 启动或切到对应应用 | 已在运行只切窗口、绝不新开实例；进程在但没窗口则弹托盘提示；图标与名称取自电脑端应用本身 |

### 2.2 语音输入（核心链路）

- 手机 `AudioRecord` 采集 **16 kHz / 16 bit / 单声道 PCM**，20 ms 一帧推到电脑。
- 电脑端写入 VB-CABLE 虚拟声卡的 `CABLE Input`，任何输入法（实测微信输入法）把 `CABLE Output` 当麦克风就能实时上屏。
- **绝不回落物理扬声器**：虚拟声卡没就绪时电脑端直接丢弃 PCM，手机端语音键置半透明、副标题显示「电脑声卡未就绪」，按下只提示「请在电脑端设置页安装或重新探测声卡」，不会起录音服务；正在说话中则会话被收掉。因为「手机说话从办公室音箱放出来」比不可用更糟。
- 麦克风权限被拒时同样禁用语音入口（副标题「无麦克风权限」）；录音服务启动失败（权限/被占用）会停掉前台服务并提示，界面不会一直停在「说话中」。
- 设备匹配策略：按关键字 `CABLE Input` 找候选，**WASAPI → DirectSound → 其它逐个试开**。WASAPI 共享模式不做重采样，VB-CABLE 默认 48 kHz 时打不开 16 kHz 流（实测 `PaErrorCode -9997`），所以不能只取第一个设备。
- 长按说话 / 双击常开：双击后进入常开，再点一次结束；松手自动收尾并释放修饰键。
- 说话中语音键显示五条波形柱并错峰循环伸缩（700ms 级），结束立即停止并复位；这只是界面动画，不参与 PCM 音频链路。

### 2.3 快捷应用（底部四栏）

- 图标是电脑应用**自己的 256×256 图标**（Shell `IShellItemImageFactory` 导出，带透明通道），名称也是应用真实名称，视觉上就是手机桌面。
- 点击行为：
  - 应用已在运行 → **只切窗口，绝不新开实例**；最小化到托盘、甚至被挪到屏幕外（`-21333,-21333`）也会先搬回主屏再置前；
  - 进程在但没有窗口 → 托盘气泡提示，不重复启动；
  - 确实没启动 → 拉起。
- 电脑端改配置后立即生效：`save()` → 热重载 → `push_apps()` 推给所有在线手机（含「等待控制权」的手机）。
- 图标首次缺失时，手机不会只剩文字：服务端发现新栏位应用没导出过图标，会先补导出再重推一帧。

### 2.4 远程粘贴

- 手机上先复制，点「粘贴」→ 电脑端写入剪贴板。
- `clip_policy` 决定是否顺带发 `Ctrl+V`：`auto`（默认，除桌面/任务栏/资源管理器外都粘）/ `always` / `caret_only`。原因：豆包、DeepSeek Harness、微信这类 Electron/Qt 应用没有 Win32 光标，只认光标会漏粘。
- 文本上限 100000 字符，手机端先校验、服务端再兜一层。

### 2.5 截屏

- 电脑端抓**全屏（含多显示器）** → 长边缩到 1600 → JPEG（quality 72，整屏约 80~400 KB）→ base64 回传。
- **全程不落盘**：电脑端只在内存编码，手机端只解码成 Bitmap，退出即回收。
- 手机端全屏浮层展示，支持双指缩放/拖动/双击在 1x ↔ 2.5x 之间切换；横屏由加速度计自判方向并强制转屏（不受系统「自动旋转」开关影响）；返回键关闭。
- 截屏只受该设备的**截图权限**约束，**不要求持有控制权**：多台遥控器同连一台电脑时，处于「等待控制权」的那台也能截屏（`screenshot` 消息不再被控制权闸门拦掉）。

### 2.6 双向文件互传

手机 → 电脑：

- **零存储权限（Android 10+）**：选图走系统 Photo Picker，选任意文件走 SAF `ACTION_OPEN_DOCUMENT`；选择上限由系统控件决定（实测 999 张 / 100 项），程序里只兜底 **一次最多 50 个**。接收落 MediaStore 同样零权限。
  **Android 8/9（minSdk 26）例外**：接收文件要写公共下载目录，需要 `WRITE_EXTERNAL_STORAGE`；未授权时会明确拒收并提示去系统设置授予，不会静默失败。
- 单文件上限 **2 GB**；不做断点续传；失败/取消的临时文件（`.part_*`）直接删除。
- 电脑端默认落**系统「下载」目录**（本机被重定向到 `D:\Downloads`，用 `SHGetKnownFolderPath(FOLDERID_Downloads)` 取真实路径，不拼 `%USERPROFILE%`），可在设置页改成任意目录并立即生效。
- 每个已绑定遥控器在设置页有**三项权限勾选：所有 / 传文件 / 截图**（默认「所有」）。勾「所有」时另两项置灰；取消「所有」后可以单独勾一项、两项，或者都不勾。
- 权限变更**实时推送给所有在线手机**（`perms` 帧，不论是否持有控制权），重连时 `auth_ok` 也会带最新的权限；没有权限的手机端点按钮会直接提示「权限受限，请在电脑端设置菜单授权。」，不会白等超时。
- 同名文件自动加 ` (1)`，**绝不覆盖已有文件**；文件名与 `transfer_id` 都做目录穿越清洗（`../`、分隔符、绝对路径）、Windows 保留名规避（按首个点前的整段判断，`nul.a.b` 也拦）、超长截断。
- **先握手再传**：手机发 `file_begin` 后等电脑端 `file_ack` 才开始推块（10 s 超时）；电脑端拒收（开关关 / 超限 / 无法创建文件）时手机**立刻停发并提示**，不会把整个文件白推一遍还报「发送完成」。
- **发送背压**：待发送队列超过 2 MB 就等电脑端消费，持续 30 s 不回落判停滞并中止——避免弱网/慢盘时 256 KB 块在内存里堆到 OOM。
- 收到的字节数不许超过声明大小，超了立刻中止。

电脑 → 手机：

- 托盘右键「发送文件到手机…」或设置页「发送文件到手机…」选文件 → 推给当前控制中的手机。
- 手机落 `Download/RemoteMic/`（MediaStore，`IS_PENDING` 写完后才可见）。

进度与后台：

- 传输期间有进度浮窗（文件名、已完成/总量、百分比、取消）。
- 浮窗底部「后台传递」：点了只收起浮窗、回到遥控器界面，传输继续。
- 传输全程由**短时前台服务**在通知栏显示进度，传完/失败自动停止（不做常驻保活）。

### 2.7 绑定与控制权

- 电脑端设置页生成二维码（含电脑名、IP、端口、绑定 token），手机用 CameraX + ZXing 扫码即完成绑定。
- 顶栏设备名：点开是已绑定电脑下拉（在线圆点、当前对勾），可直接切换；底部「绑定新设备」进入扫码。
- 设备管理底部抽屉：**只能扫码绑定**（手动输入 IP/token 的入口已移除）、连接状态变化后**列表当场刷新**（不用退出来再重进）；每行显示在线圆点、电脑名、`host:port` 与删除按钮；**底部显示 App 版本号**（如「手机遥控麦 v1.2.0」）。
- 多台手机：**先连优先**，后连的进入「等待控制权」；托盘「切换控制遥控器」或设置页可手动指定。
- 「等待控制权」只拦**控制类**操作（按键、语音、置前、剪贴板、麦克风）；**传文件、截屏、以及主动请求接管控制权**在待命状态同样有效——这两件事不抢键盘焦点与出声，只按该设备自己的权限走。
- 设置页可删除某个遥控器（token 失效后需重新扫码）。

### 2.8 连接保活策略

**不做后台常驻**（不申请前台服务常驻、不拿 WakeLock、不加电池优化白名单）。熄屏后系统会挂起网络、连接会断，这被认为是合理行为。改为在**亮屏 / 解锁 / 回到界面**时立刻探活并重连（实测亮屏→重连 0.3 秒）。

### 2.9 界面与交互（Android 1.1.0 重设计）

- **六分区**：顶栏 / 媒体 / 工具与文件 / 方向 / 语音 / 快捷，整页一屏不滚动；顶栏 48dp、媒体区 56dp，方向区用剩余高度。
- **环形方向键**：白色环带 + 四段可点，按下对应段变浅蓝、箭头放大 1.16 倍并触发触感；中心「视频」圆钮仍是空格键。环带尺寸随可用高度缩放（最低约 190dp）。
- **语音键**：未按下浅蓝渐变，说话中同色相加深一档并显示五条循环波形；仍是原来的按住 / 双击常开 / 单击结束三种状态。
- **退格**：单击删一个；长按约 350ms 后开始连删，间隔从 120ms 逐次加快到 34ms，松手立即停。
- **反馈**：所有可点控件按下有 0.95 缩放 + `KEYBOARD_TAP` 震动；设备下拉、底部抽屉为自绘，带同样的点击反馈。
- **玻璃质感**：卡片是半透明白 + 1px 白描边 + 阴影；设备抽屉为实白底（Android 无 `backdrop-filter`，半透明会让下面的图标透出来，影响可读性）。
- **系统栏**：按 `WindowInsets` 的 systemBars 给顶栏/底栏留白，兼容 Android 15 边到边，顶栏不再被状态栏压住。
- 这一版只改界面与交互层，**协议、电脑端注入、音频链路均未改**。
  （后续的 **1.2.0** 是稳定性加固轮：界面布局不变，但改了文件传输握手与背压、语音键就绪门禁、电脑端锁粒度与线程模型，详见 [v1.2.0 发布说明](release-notes-v1.2.0.md)。）

### 2.10 下拉快捷开关（控制中心磁贴）

- 系统的下拉快捷开关里会多出一个「**遥控麦**」磁贴（麦克风图标），点一下就切到本应用，不用回桌面找图标。
- 磁贴**不承载连接状态**：始终是灰色未激活样式，连接与否看应用内顶栏；不申请任何额外权限、不常驻、不息屏保活。
- 点磁贴的打开行为与点桌面图标一致：应用在后台时**复用原来的任务栈**（不会开出第二个界面），进程被系统或强制停止后点击是正常冷启动。
- Android 14 起系统禁止后台直接启动界面，磁贴走 `PendingIntent` 通道，这条路径已适配，锁屏状态下点磁贴会被系统拦下（属系统行为，解锁后正常）。
- 首次安装后部分机型（ColorOS 等）不会自动摆放：下拉面板点「编辑」把「遥控麦」拖进开关列表即可，之后一直留在面板上。

## 三、电脑端功能

### 3.1 托盘

| 菜单项 | 说明 |
| --- | --- |
| 状态：… | 图标颜色随连接状态变化（灰=未绑/离线，绿=在线，黄=在线但无控制权） |
| 切换控制遥控器 | 子菜单列出所有遥控器，`●` 当前控制中 |
| 发送文件到手机… | 原生多选 → 推给控制中的手机 → 托盘气泡回执 |
| 开机自动启动 | 勾选项，写 `HKCU\...\Run` 的 `RemoteMic` 值 |
| 设置… | 打开设置页 |
| 退出 | 释放修饰键、停服务 |

### 3.2 设置页（pywebview）

- **电脑信息**：电脑名（手机顶栏显示）、局域网地址、端口、**电脑端版本号**、**项目仓库链接**（点击用系统默认浏览器打开）、配置保存位置。
- **音频输出（虚拟声卡）**：当前匹配到的设备、匹配关键字、「重新探测声卡」；**驱动没装时**显示「未检测到 VB-CABLE」提示条 + 「安装虚拟声卡」按钮（静默 `-i -h`，必要时弹一次 UAC，装完自动重开输出流）。
- **文件互传**：接收目录（更改/恢复默认/打开）、限制说明（2 GB、50 个）、「发送文件到手机…」。
- **已绑定遥控器**：名称、上次 IP、绑定时间、在线状态、**权限（所有 / 传文件 / 截图）**、删除；「生成绑定二维码」。权限改动即时生效并推送给在线手机。
- **快捷应用栏位**：四个栏位选应用（带图标的应用列表，支持搜索）＋栏位级发送快捷键（无 / enter / ctrl+enter）。
- 保存后热重载并关闭窗口；图标异步补齐，页面秒开。

### 3.3 服务端行为

- WebSocket 监听 `0.0.0.0:8765`，首帧 token 认证；认证成功回 `auth_ok`（含 `perms.files` / `perms.screenshot`，并保留 `files_allowed` 兼容旧版手机端）。
- 断线重连：重复登录顶掉旧连接前先 `_close_quietly()`（1.5 s 超时 + 吞异常），避免死 socket 的关闭握手堵死事件循环（历史上表现为手机每 10 s 掉线、`pong` 超时）。
- 启动时清理 24 h 前的 `.part_*` 残留。
- 日志 `%LOCALAPPDATA%\RemoteMic\logs\service.log`（5 MB × 3 滚动）；配置 `%LOCALAPPDATA%\RemoteMic\config.json`（首次从仓库旧路径自动迁移）。

## 四、边界与已知限制

| 项 | 现状 |
| --- | --- |
| 网络 | 仅同一局域网；不做公网穿透、不走云端 |
| 音频 | 未压缩 PCM（16 kHz/16 bit/单声道）；带宽差时可能卡顿，未上 Opus |
| 文件 | 不做断点续传；单文件 2 GB、一次 50 个；不做会话总量控制 |
| 后台 | 不做常驻保活；熄屏断连属预期 |
| 界面 | 卡片用半透明白近似毛玻璃（Android 无 `backdrop-filter`）；设备抽屉/下拉用实白底；小屏上方向环会缩到约 190dp |
| 安全 | token 认证 + 局域网自用；token 泄露需在设置页删除重绑；防火墙只放行专用/域网络的 8765 |
| 平台 | 电脑端仅 Windows 10/11 x64；手机端 Android 1.1.0（一加 13 / ColorOS 17 实测） |
| 签名 | 安装包与驱动均未做商业签名（VB-CABLE 为 VB-Audio 自签），SmartScreen 首次运行会提示未知发布者 |
