# v1.2.2 · 下拉快捷开关：点一下直接切到应用

发布日期：2026-11-21

## 下载

- **手机端**：`RemoteMic-1.2.2.apk`（Android 8.0+，约 6 MB，`versionCode=5`）
- **电脑端**：`RemoteMicSetup-1.1.1.exe`（Windows 10/11 x64，约 28 MB；本版电脑端无代码改动，沿用 1.1.1）

## 新功能：下拉快捷开关（控制中心磁贴）

系统的下拉快捷开关里会多出一个「**遥控麦**」磁贴（麦克风图标），点一下直接切到本应用，不用回桌面找图标。

- **不承载连接状态**：磁贴始终是灰色未激活样式，连接与否看应用内顶栏。不做开/关切换语义，避免"看着是开着其实没连上"的误会。
- **不常驻、不额外权限**：不申请前台服务、不休眠保活、不拿 WakeLock，只是系统里的一个可点入口。
- **打开行为与桌面图标一致**：应用在后台时复用原来的任务栈，不会开出第二个界面实例；进程被系统回收或手动强制停止后点击是正常冷启动。
- **Android 14+ 适配**：从 Android 14 起系统禁止后台用 `Intent` 直接启动界面，磁贴对 API 34+ 改走 `PendingIntent` 通道，低版本仍走旧接口，同一份代码覆盖 minSdk 26～35。
- **需要手动摆放的机型**：部分 ROM（ColorOS 等）安装后不会自动把磁贴放进面板。下拉面板点「编辑」，把「遥控麦」拖进开关列表即可，之后一直保留。

## 升级方式

- **1.2.1 → 1.2.2 直接覆盖安装**，同 release 签名，绑定列表与 token 全部保留，装完即可用（实测顶栏仍显示原设备并「控制中」）。
- **1.2.0 及更早**仍需卸载重装（debug 签名 → release 签名不兼容），会丢绑定、需重新扫码一次。

## 验证

- `aapt dump badging`：`versionName='1.2.2'`、`versionCode='5'`。
- `apksigner verify --print-certs`：签名者 `CN=xjyfy RemoteMic`，指纹 `6567fa4f…4344cd`，与 `signing/` keystore 一致。
- 真机（一加 13 / ColorOS 17）从 1.2.1 覆盖安装 1.2.2：绑定保留、连接正常、界面与按键功能不受影响。
- 磁贴三种场景实测：前台→回桌面→点磁贴（回到原任务栈，未新建实例）；`force-stop` 杀进程后点磁贴（冷启动成功）；锁屏状态下点磁贴被系统拦下（`device could not interactive`），解锁后正常。

## 已知限制

- 锁屏状态下点磁贴不会启动应用，这是系统对后台启动界面的限制，解锁后再点即可。
- 磁贴不显示"是否已连接"；要确认连接状态请打开应用看顶栏，或看电脑端托盘状态点。
