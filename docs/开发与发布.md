# 开发与发布

> 三件事：改手机端怎么编译、改电脑端怎么打 exe、发版怎么出安装包与 GitHub Release。

---

## 一、目录结构

```
android-app/         手机端（Kotlin / Gradle 8.9 / AGP 8.x）
pc-service/          电脑端（Python 3.12）
  remote_mic/        服务端包（server / actioner / audio_out / files / tray / settings_web …）
  vendor/vb-cable/   VB-CABLE 驱动包（随安装包分发，2.9 MB）
  RemoteMicService.spec  PyInstaller 打包脚本
  build_installer.ps1    一键：PyInstaller → 自检 → ISCC
installer/           Inno Setup 脚本与发布依赖
  RemoteMic.iss      安装包定义
  lang/              简体中文语言包
  redist/            WebView2 Evergreen 引导器（1.7 MB）
docs/                文档（本目录）
```

## 二、手机端构建

前置（本机实测）：JDK 17、Android SDK。

```powershell
$env:JAVA_HOME='D:\Java\jdk-17.0.21+9'
$env:ANDROID_HOME=$env:ANDROID_SDK_ROOT='D:\Android\SDK'
cd android-app
.\gradlew.bat assembleDebug --console=plain
# 产物：app\build\outputs\apk\debug\app-debug.apk
```

安装到手机（签名一致可直接覆盖，绑定信息保留）：

```powershell
& 'D:\Android\SDK\platform-tools\adb.exe' -s <序列号> install -r app\build\outputs\apk\debug\app-debug.apk
```

打包机注意：`gradle-wrapper.jar` 若缺失，执行 `gradle wrapper --gradle-version 8.9 --no-validate-url`（**必须带 `--no-validate-url`**，否则国内网络下 `services.gradle.org` 的 HEAD 校验会超时）。

## 三、电脑端运行（开发期）

```powershell
cd pc-service
.\安装依赖.bat        # 首次
.\启动电脑端服务.bat
```

或直接 `python run.py`（控制台可见日志）。依赖清单见 `pc-service/requirements.txt`；新增依赖用：

```powershell
uv pip install --python .venv\Scripts\python.exe <包名>
```

日志在 `%LOCALAPPDATA%\RemoteMic\logs\service.log`。

## 四、打安装包

### 4.1 前置

| 依赖 | 安装方式 | 说明 |
| --- | --- | --- |
| PyInstaller | `uv pip install --python .venv\Scripts\python.exe pyinstaller` | 已在本机 `.venv` 里 |
| Inno Setup 6 | `winget install --id JRSoftware.InnoSetup -e` | 本机装在 `%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe` |
| VB-CABLE 驱动包 | 解压到 `pc-service\vendor\vb-cable\` | 官方 `VBCABLE_Driver_Pack43.zip`，需含 `VBCABLE_Setup_x64.exe` |
| WebView2 引导器 | 放到 `installer\redist\MicrosoftEdgeWebview2Setup.exe` | 官方 Evergreen Bootstrapper |

### 4.2 一条命令

```powershell
pwsh -ExecutionPolicy Bypass -File pc-service\build_installer.ps1
```

内部三步：

1. `pyinstaller --noconfirm --clean pc-service\RemoteMicService.spec` → `pc-service\dist\RemoteMicService\`（onedir，约 82 MB）
2. 自检 `RemoteMicService.exe --check-driver`（退出码 0/1 都算正常）
3. `ISCC.exe installer\RemoteMic.iss` → `dist-installer\RemoteMicSetup-1.0.0.exe`（约 27 MB）

`build_installer.ps1` **必须存为 UTF-8 BOM**：Windows PowerShell 5.1 会把无 BOM 的 UTF-8 当 ANSI 读，中文注释会变乱码并报「字符串缺少终止符」。

### 4.3 打包约束（踩过的坑）

- **onedir，不要 onefile**：onefile 每次启动解包到临时目录，常驻托盘程序冷启动明显变慢、杀软误报更多。
- **不开 UPX**：压过的 exe 更容易被杀软误报。
- **GUI 子系统**（`console=False`）：双击不弹黑框；`--install-driver` 用弹窗反馈结果。
- 随包资源路径：`vb-cable` 会落在 `{app}\_internal\vb-cable\`，`installer\RemoteMic.iss` 里按这个路径调安装器；改 spec 的布局要同步改 iss。
- `PrivilegesRequired=admin` 又写 HKCU 会触发 Inno 的 `UsedUserAreasWarning`：同机同用户提权是同一个 Hive，正常；换管理员账号安装时自启会落到那个账号。

### 4.4 安装包做了什么

| 阶段 | 动作 |
| --- | --- |
| 装前检测 | `RemoteMicService.exe --check-driver` 判断驱动是否已装；注册表判断 WebView2 |
| 安装 | 解包到 `%ProgramFiles%\RemoteMic`；WebView2（按需静默装）；VB-CABLE `-i -h`；防火墙规则（仅 private/domain）；可选自启（HKCU Run，默认不勾）；可选桌面图标 |
| 装后自检 | `CurStepChanged(ssPostInstall)` 再查一次驱动，没装上就提示并指向设置页的重试入口 |
| 卸载 | 杀进程 → 删防火墙规则 → 删自启 → 询问是否卸载 VB-CABLE → 询问是否删 `%LOCALAPPDATA%\RemoteMic` |

## 五、发版到 GitHub

代码推仓库（注意本机需要代理且禁 HTTP/2，否则 `stream 1 was not closed cleanly`）：

```powershell
git -c http.proxy=http://127.0.0.1:1080 -c https.proxy=http://127.0.0.1:1080 ^
    -c http.version=HTTP/1.1 push origin main
```

安装包**不进 Git**（`.gitignore` 已屏蔽 `dist-installer/`），走 GitHub Release 资产：

```powershell
gh release create v1.0.0 'dist-installer\RemoteMicSetup-1.0.0.exe' ^
   --title "v1.0.0 · 双向文件互传 + 托盘发送 + 安装包" ^
   --notes-file docs\release-notes-v1.0.0.md
```

已发布：<https://github.com/xjyfy/bed-work/releases/latest>

发版检查单：

- [ ] `docs/` 里的功能变化已同步（功能说明 / 安装与使用 / 架构与协议）
- [ ] `build_installer.ps1` 跑通，拿到新的 setup.exe
- [ ] 安装包至少在一台干净机器做过装→用→卸
- [ ] Release Notes 写清新增功能、已知限制、升级方式（覆盖安装不丢 `config.json`）

## 六、常见开发问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 手机端一发送就崩 `Can't toast on a thread...` | 后台线程直接调 `Toast`；所有回调包 `runOnUiThread` |
| 手机端崩 `ForegroundServiceDidNotStartInTimeException` | `startForegroundService()` 后 5 s 内没 `startForeground()`；在 `onCreate` 里立刻进前台，且停止服务要等启动满 6 s |
| 手机每 10 s 掉线、`pong` 超时 | `await ws.close()` 对死 socket 会等完整关闭握手（10 s）堵死事件循环；用 `_close_quietly()`（`asyncio.wait_for` 1.5 s） |
| 快捷应用切不过来 | 窗口在 `(-21333,-21333)` 时 API 全返回成功但人看不见；判据要加「窗口真的在虚拟桌面内」 |
| 托盘勾选删不掉 | `winreg.OpenKey` 默认只读；删值要 `OpenKey(..., 0, KEY_SET_VALUE)` |
| 设置页打不开 | 缺 WebView2；或 `pywebview` 没在主线程调用 |
| 打包后找不到驱动安装器 | `paths.vendor_dir()` 在 frozen 下取 `_MEIPASS`，即 `_internal\vb-cable` |
