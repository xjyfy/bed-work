# v1.1.0 · 手机端全新界面（Android APK）

发布日期：2026-11-21

## 下载

- **手机端**：`RemoteMic-1.1.0.apk`（Android 8.0+，约 6 MB）
- **电脑端**：`RemoteMicSetup-1.0.3.exe`（Windows 10/11 x64，约 28 MB；本版未改，沿用 1.0.3）

## 手机端 1.1.0（本次重点）

这一版是界面与交互重设计，**协议、电脑端注入、音频链路都没有改**，可与电脑端 1.0.3 直接混用。

- **六分区一屏布局**：顶栏 / 媒体 / 工具与文件 / 方向 / 语音 / 快捷；工具与文件互传合并为一张卡。
- **环形方向键**：白色环带 + 四段可点，按下对应段变浅蓝、箭头放大并触发触感；中心「视频」圆钮仍是空格键。
- **语音键新配色**：未按下浅蓝渐变，说话中同色相加深一档；说话中显示五条循环波形，结束立即停止。
- **设备菜单**：顶栏点设备名下拉切换已绑定电脑；设置入口改为底部玻璃抽屉，扫码/删除/切换逻辑不变。
- **退格长按加速连删**：单击删一个，长按约 350ms 后开始连删，间隔从 120ms 逐步加快到 34ms，松手立即停。
- **所有按键反馈**：按下 0.95 缩放 + 系统触感；保留原有全部按键映射。
- **边到边适配**：按状态栏/导航栏 inset 留白，Android 15 顶栏不再被状态栏压住。
- **顶栏/媒体区压缩**：顶栏 48dp、媒体区 56dp，给方向区让出空间；方向环上下留呼吸，滚轮两键拉开间距。
- **玻璃质感**：半透明白卡片 + 白描边 + 阴影；抽屉/下拉用实白底保证可读（Android 无 `backdrop-filter`）。

## 安装与升级

- APK 使用本机 **debug 签名**（与之前的开发版同签名），可以**直接覆盖安装，手机端已绑定电脑不会丢**。如果要公开分发/上架，请换正式 release keystore 后重新发版（换签名后需卸载重装）。
- 电脑端安装包未签名，SmartScreen 首次运行会提示「未知发布者」，属预期。
- 电脑端升级不会覆盖 `%LOCALAPPDATA%\RemoteMic\config.json`。

## 已知限制

- 卡片是半透明近似毛玻璃，不是实时背景模糊；设备抽屉/下拉为实白底。
- 声音仍是 16 kHz/16 bit/单声道未压缩 PCM；弱网卡顿未上 Opus。
- 文件互传无断点续传；单文件 ≤ 2 GB、一次 ≤ 50 个。
- 小屏上方向环会缩到约 190dp；已尽量保留间隙。

## 验证

- `assembleRelease` 通过；`apksigner` 显示 APK 签名与开发版一致；`aapt` 确认 `versionName=1.1.0`、`versionCode=2`。
- 一加 13 / ColorOS 17 真机覆盖安装成功，原绑定保留；主界面、方向环按压、说话中波形、设备下拉、设备管理抽屉、退格长按均实测。
