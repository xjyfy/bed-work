# 安装与使用

> 两条路：**普通使用**直接装安装包；**开发调试**用仓库里的 `.venv` 跑。

---

## 一、普通使用（安装包）

### 1.1 电脑端下载与安装

从 [Releases](https://github.com/xjyfy/bed-work/releases/latest) 下载 `RemoteMicSetup-1.1.1.exe`（约 28 MB），双击安装。

- 安装位置：`%ProgramFiles%\RemoteMic`（需要管理员，UAC 弹一次）。
- 安装过程会自动：解包程序 → 缺 WebView2 时联网静默安装运行时 → 装 VB-CABLE 虚拟声卡（`-i -h`，已装则跳过）→ 添加防火墙规则「RemoteMic 8765」**只放行专用/域网络** → 可选「开机自动启动」（默认不勾）→ 可选桌面图标 → 启动服务。
- 运行期数据在 `%LOCALAPPDATA%\RemoteMic\`（`config.json`、`logs\service.log`），升级不会覆盖。

### 1.2 手机端

1. 从同一个 Release 页下载 `RemoteMic-1.2.1.apk`（Android 8.0+，约 6 MB）。**若装过 1.2.0 或更早的 debug 签名版，先卸载再装**（签名不同无法覆盖；卸载会丢绑定，装好后重新扫码一次）。1.2.1 之后的版本可直接覆盖升级。
2. 电脑托盘右键 →「设置…」→「生成绑定二维码」。
3. 手机 App 里扫码 → 自动填电脑地址与 token。
4. 手机顶栏出现「控制中」即可使用。

说明：

- APK 自 1.2.1 起使用**独立 release 签名**（keystore 存仓库 `signing/`、不进 Git），同签名后续版本可直接覆盖安装、**绑定不丢**；但从 1.2.0 及更早的 debug 签名版升级必须先卸载（丢绑定，重扫一次）。签名与密钥管理见 [开发与发布](开发与发布.md)。
- 顶栏点设备名可下拉切换已绑定电脑；点右侧设置按钮打开底部「设备管理」；设备管理里仍然只能扫码绑定。
- 退格键支持**长按加速连删**：单击删一个，按住约 350ms 后开始连删并逐步加快。
- **建议两端一起升级到 1.2.0 / 1.1.0**。本版改了文件传输握手（手机等 `file_ack` 才推块）：新手机配旧电脑端仍能传（旧电脑端本来就回 ack），但「拒收立刻停发」「发送背压」等保护要两端都升级才完整。
- 语音键在**电脑端虚拟声卡未就绪**时会变半透明、副标题显示「电脑声卡未就绪」，按下只提示不起录音；去电脑端设置页「安装虚拟声卡」或「重新探测声卡」即可恢复，手机端无需重启。麦克风权限被拒时同理显示「无麦克风权限」。

### 1.3 第一次用语音

语音写进虚拟声卡，需要让输入法把 `CABLE Output` 当麦克风：

1. 电脑端设置页「音频输出（虚拟声卡）」应显示**已就绪**（匹配到 `CABLE Input`）。
2. 打开微信输入法 → 设置 → 语音/麦克风 → 输入设备选 **CABLE Output (VB-Audio Virtual Cable)**。
3. 手机上「按住说话」，说话内容就会实时上屏；双击是常开，说话中语音键会显示跳动的波形。

如果设置页显示「未检测到 VB-CABLE」：

- 点卡片里的**「安装虚拟声卡」**按钮（会弹一次 UAC），装完自动重开输出流，不用重启服务；
- 命令行等价：`"C:\Program Files\RemoteMic\RemoteMicService.exe" --install-driver`；
- 装完仍不生效 → 点「重新探测声卡」；再不行看 [排障](#五排障)。

### 1.4 传文件

- 手机 → 电脑：手机点「照片」（系统 Photo Picker）或「文件」（SAF），选完点「添加」，默认发给当前界面选中的那台电脑，落在电脑的**系统「下载」目录**。
- 电脑 → 手机：托盘右键「发送文件到手机…」，或设置页「文件互传」里的同名按钮；手机落在 `Download/RemoteMic/`。
- 想改电脑接收目录：设置页「文件互传」→「更改目录」，立即生效无需保存。
- 不想让某台手机往电脑发文件：设置页遥控器表里取消该行的「接收文件」。

### 1.5 开机自启

托盘右键勾「开机自动启动」即可（写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，值名 `RemoteMic`）。安装包里的同名勾选项与它是同一个值，装完状态一致。

服务必须是**独立进程**（`RemoteMicService.exe`），不要从别的应用（如豆包、编辑器）把它当子进程拉起，否则宿主退出会连带停服。

### 1.6 卸载

控制面板 → 应用 → 卸载「手机遥控麦」。卸载过程：

1. 结束 `RemoteMicService.exe`；
2. 删除防火墙规则；
3. 删除自启项；
4. **询问**是否卸载 VB-CABLE（会提醒：录像/直播等其他软件可能也在用 CABLE，卸了会一起失效）；
5. **询问**是否删除 `%LOCALAPPDATA%\RemoteMic`（含绑定 token，删了手机要重新扫码）。

## 二、开发调试（仓库直接跑）

```powershell
cd pc-service
.\安装依赖.bat          # 首次：建 .venv（uv 或 python -m venv）并装依赖
.\启动电脑端服务.bat    # 双击即可，隐藏窗口，不留命令行
```

- `启动电脑端服务.bat` 只做一件事：`start "" wscript.exe start-hidden.vbs`；`start-hidden.vbs` 按序找解释器（仓库 `.venv` → 旧 Python 3.13 → PATH），失败弹窗给出退出码与日志尾部。
- 日志：`%LOCALAPPDATA%\RemoteMic\logs\service.log`；开发期首次启动会把仓库 `pc-service\config.json` 自动迁移到 `%LOCALAPPDATA%\RemoteMic\config.json`（旧文件保留）。
- 直接跑单文件也行：`python pc-service\run.py`（会同时输出到控制台）。
- 驱动命令：`python run.py --check-driver`（退出码 0=已装）、`--install-driver`、`--uninstall-driver`。

主要配置项（`config.json`）：

| 字段 | 说明 |
| --- | --- |
| `computer_name` | 手机顶栏显示的电脑名 |
| `remotes[]` | 已绑定遥控器（`id` / `name` / `token` / `receive_files`） |
| `apps{1..4}` | 四个快捷应用栏位的 exe 路径，或 `uwp:<AUMID>` |
| `slot_send_hotkey{}` | 栏位级发送键：`enter` / `ctrl+enter`（留空=按前台程序查表） |
| `voice_hotkey` | 语音键组合，默认 `ctrl+win` |
| `clip_policy` | 远程粘贴是否补 `Ctrl+V`：`auto` / `always` / `caret_only` |
| `download_dir` | 手机传来文件的落盘目录，空=系统「下载」 |
| `audio_device_keyword` | 虚拟声卡匹配关键字，默认 `CABLE Input` |

## 三、防火墙

安装包会自动加规则（只对专用/域网络）：

```powershell
netsh advfirewall firewall add rule name="RemoteMic 8765" dir=in action=allow ^
  protocol=TCP localport=8765 program="C:\Program Files\RemoteMic\RemoteMicService.exe" profile=private,domain
```

- 手机连不上时先确认当前网络是「专用网络」而不是「公用网络」，否则规则不生效。
- **历史坑**：本机曾给 `pythonw.exe` 加过入站 Block 规则，导致手机连不上；打包后主程序是自己的 exe，规则按 exe 精确放行，但排查时仍要检查是否有旧的 `pythonw` 规则。

## 四、WebView2

设置页是 pywebview，依赖系统的 **WebView2 Runtime**：Win11 一般自带，Win10 可能没有。

- 安装包检测注册表（`EdgeUpdate\Clients\{F3017226-...}` 的 HKLM 32/64 位与 HKCU 视图），缺失时才运行随包的 `MicrosoftEdgeWebview2Setup.exe /silent /install`（联网下载约 100 MB 运行时）。
- 没有 WebView2 且装不上时，服务仍可用，设置页会回退到 tkinter 版（`settings_ui.py`）。

## 五、排障

| 现象 | 处理 |
| --- | --- |
| 手机连不上 | 检查服务是否在跑（托盘图标）；防火墙规则/网络位置；手机与电脑是否同一网段 |
| 连上又每 10 秒掉一次 | 旧版本 bug（关闭握手堵死事件循环），升级到当前版本 |
| 手机说话电脑没反应 | 设置页看虚拟声卡是否「已就绪」；设备装没装；输入法拾音设备是否选 `CABLE Output` |
| 设置页提示未检测到 VB-CABLE | 点「安装虚拟声卡」；企业策略/Secure Boot 可能拦截未签名驱动 |
| 快捷应用点了没反应 | 应用在托盘/屏幕外也会被搬回并置前；若显示「已有窗口但无法置前」是应用自身拒绝前台化 |
| 截图/文件传输中途失败 | 看 `service.log` 里的 `file begin / file received / file aborted`；`.part` 文件会被自动清理 |
| 安装后首次运行报「未知发布者」 | 安装包未做代码签名，属预期；确认下载来源后继续 |
