# v1.2.8 发布说明

**手机端 1.2.8（versionCode 11）/ 电脑端 1.1.6**

本次只修电脑端设置页的快捷键交互缺陷，协议与按键行为不变。

## 修复

### 1. 改任意快捷键后应用图标消失

**原因**：图标是异步补进界面的，只写进了页面元素，没有回写到栏位状态。改完快捷键会触发一次栏位重绘，重绘出来的新行没有图标，于是四个图标一起没了。

**修复**：图标补好后同时记进栏位状态；重绘时保留已有图标；新选应用后重绘再补一次图标。现在改多少次快捷键、换多少次应用，图标都不会闪没。

### 2. 点「恢复默认」后无法再设置，必须重开设置页

**原因**：恢复默认会重建整张栏位表，刚点过的按钮随之失效，后续点击落到已经不在页面上的旧按钮上。

**修复**：恢复默认、以及任何快捷键变更都不再重建表格，只就地刷新那一行按钮的文字和状态。恢复默认之后可以直接接着点下一个快捷键。

### 3. 「恢复默认」只复位一项

`↺` 按钮移到了两行快捷键右侧，一次同时复位两项：

| 项 | 恢复成 |
| --- | --- |
| 发送键 | 无（回落 `Enter`） |
| 新会话键 | 默认（`Ctrl+N`） |

## 附带

- 设置页说明文案改为「快捷键（点一下再按键）」；`↺` 悬浮提示写明复位后的两个值。
- 服务启动日志仍会打印 `app slot icons ready: N`，便于确认图标抓取正常。

- 电脑端：直接安装 `RemoteMicSetup-1.1.6.exe` 覆盖，配置与手机绑定不受影响。
- 手机端：`RemoteMic-1.2.8.apk` 覆盖安装，签名一致（证书 SHA-256 `6567fa4f…9e4344cd`），绑定保留。
